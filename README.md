# ЦРВУ: лендинг выставочных стендов, версия для проверки (v2)

Исправленная версия лендинга по итогам аудита от 10.10.2026. Исходный репозиторий `crvu-stendy-landing` не изменён.

Статический сайт без сборки. Корень: `index.html`.

Режим предпросмотра включён в `assets/js/config.js` (`preview: true`): формы проверяют данные, но заявки не отправляют, Метрика не загружается, страница закрыта от индексации.

Перед запуском на боевом домене нужны: адрес приёма заявок, подтверждённые цены и коэффициенты, реквизиты юрлица, реальные фото цеха и интервью клиентов. Список правок и открытых вопросов находится в проекте «ЦРВУ лендинг», файл `REVIEW_V2_CHANGES.md`.
